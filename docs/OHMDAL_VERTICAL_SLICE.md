# Ohmdal Vertical Slice

## Objetivo

Construir una base tecnica extensible para Hub + Ohmdal, no el juego completo.

## Alcance inicial

- Hub placeholder.
- Roxana placeholder.
- Player placeholder.
- Movimiento desktop y mobile.
- Dialogo React iniciado desde Phaser.
- Bitacora React con contenido JSON.

## Siguiente capa sugerida

- Mapa Tiled placeholder para el Hub.
- Primer portal hacia Ohmdal.
- Tres puzzles de electricidad con reglas separadas en `src/game/puzzles`.
- Entrada de bitacora de mundo para Ohmdal.
