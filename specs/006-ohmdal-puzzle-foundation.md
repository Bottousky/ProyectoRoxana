# Spec 006 - Ohmdal Puzzle Foundation

## Objetivo

Preparar las reglas de diseno y arquitectura para los primeros puzzles de electricidad en Ohmdal.

## Alcance propuesto

- Tres puzzles de electricidad para el vertical slice.
- Reglas de puzzle separadas de escenas Phaser.
- Feedback visual dentro del mundo jugable.
- Bitacora de mundo para explicaciones formales.
- Dialogos con pistas indirectas.

## Fuera de alcance

- Evaluacion educativa formal.
- Backend de progreso.
- Sistema de recompensas completo.

## Criterios de aceptacion

- Los puzzles se pueden testear como reglas o sistemas independientes.
- Phaser adapta estado a visuales y colisiones.
- React solo muestra bitacora, dialogos o UI textual mediante eventos.
- Ningun NPC da definiciones directas de conceptos cientificos.
